## 🪙 Featured project
**[Gold Oracle](https://github.com/DoddiNavadeepReddy/Gold-oracle)** tracks global gold futures and USD/INR rates, applies GST and import duty, and forecasts 2026 price trends with scikit-learn. It includes automated data cleaning and Seaborn volatility heatmaps.
