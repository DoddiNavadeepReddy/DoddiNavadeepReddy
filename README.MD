> ### [Gold-oracle](https://github.com/DoddiNavadeepReddy/Gold-oracle)
>
> A Python analytics tool for gold prices. It pulls two years of gold futures and USD/INR data from Yahoo Finance, converts the price to ₹ per gram with an import-duty and GST adjustment, and fits linear-regression models to project monthly price trends. Includes data cleaning, a trend chart, and a correlation heatmap.

### [Network Intrusion Detection](https://github.com/DoddiNavadeepReddy/Hackthon_NERD1)

A hackathon team project using the NSL-KDD dataset to classify normal traffic and DoS, Probe, R2L, and U2R attacks, extended from a public Kaggle baseline. It compares four models, selects XGBoost by cross-validation, and documents the hard classes (R2L and U2R). Includes SHAP explanations, a FastAPI service, and a React dashboard.

`Python` `scikit-learn` `XGBoost` `SHAP` `FastAPI` `React`
